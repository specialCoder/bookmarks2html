Privacy Policy

bookmarks2html · Chrome extension

← Back to the extension page

TL;DR — bookmarks2html collects no personal data, uploads nothing, and contains no analytics or advertising code. Your bookmarks are read from Chrome's own local API and rendered locally. The extension makes no network requests at all unless you explicitly turn on "Fetch page descriptions" in settings.

Last updated: 2026-10-03

What we do

The extension's single purpose is to display your existing Chrome bookmarks as a card-based new tab page. It reads the bookmark tree through the chrome.bookmarks API, reads site icons through Chrome's local favicon cache, and renders both in the page. Settings are stored in chrome.storage.sync so they follow your own signed-in Chrome profile.

What we do not do

  • We do not collect, transmit or sell any personally identifiable information.
  • We do not operate a server, and the extension never sends your data anywhere.
  • We do not read browsing history, cookies, form input or page content of the sites you visit.
  • We do not run analytics, telemetry, or third-party trackers of any kind.
  • We do not modify your bookmarks — the extension only reads them.

The optional "Fetch page descriptions" feature

This feature is off by default. When you turn it on, Chrome asks you to grant the extension permission to read and change site data. Only then does the extension visit the URLs of your own bookmarks to read each page's description (its <meta name="description"> or equivalent text), limited to the first 200 KB of the response.

  • Requests are sent without credentials, so no cookies or login sessions are attached.
  • Results are cached in chrome.storage.local on your device (30 days on success, 1 day before retrying a failure) and are never uploaded.
  • Turning the feature off immediately revokes the host permission and clears the cached descriptions.

Local and synced storage

The extension stores only:

  • Interface settings — language, theme, view mode, card size, display toggles, search engine — in chrome.storage.sync, so your preferences follow your Chrome profile.
  • Cached page descriptions in chrome.storage.local, and only if you enabled the feature above.

All of it stays on your device (or in your own Chrome account), and is removed when you uninstall the extension.

Permissions

Each permission exists solely to deliver the bookmark homepage described above:

  • bookmarks — read the bookmark tree and listen for changes so the page stays current. Read-only; the extension never writes or deletes bookmarks.
  • favicon — request site icons from Chrome's local favicon service. This is a local chrome-extension:// endpoint, not a network request.
  • storage — remember your interface settings and cache descriptions.
  • Host access (optional, on request only) — requested only when you turn on "Fetch page descriptions", so the extension can open the bookmark URLs you already have and read their description text. Declining leaves the feature off; the extension has no host access by default.

Children's privacy

The extension does not knowingly collect any information from anyone, including children. It is a local bookmark viewer.

Changes to this policy
