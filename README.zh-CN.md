# 书签卡片（Bookmarks to Cards）

[English](README.md) | **简体中文**

一个 Chrome 扩展（Manifest V3），把浏览器里已有的书签变成美观、易读的卡片式主页。
纯原生 JS/CSS 实现，**零构建、零第三方依赖**，以「加载已解压的扩展程序」方式安装即可使用。

核心设计原则：**扩展自身不采集任何数据。** 书签内容全部由浏览器本地 API（`chrome.bookmarks`）
提供，扩展只负责读取与展示；唯一的网络行为是用户在设置里主动开启的「抓取网页简介」。

## 功能特性

- **接管新标签页** —— `Ctrl`/`⌘` + `T` 即书签主页；点击工具栏图标也会在新标签页打开主页（不使用弹窗）。
- **卡片式书签网格** —— 每个书签一张卡片，网站图标取自 Chrome 本地 favicon 缓存；取不到时回退为
  由标题/域名生成的彩色首字母，**永不出现裂图**。
- **文件夹 Tab + 面包屑下钻** —— 顶部按书签栏一级文件夹的子文件夹生成 Tab；点进文件夹后仍可继续
  下钻子目录，面包屑随时回退。
- **即时搜索** —— 输入即过滤全部书签，命中关键词高亮，可显示每条结果所在文件夹路径；
  无结果时按回车用所选搜索引擎（Google / Bing / 百度）搜索网页。
- **网页简介（可选，默认关闭）** —— 开启后由 service worker 读取书签页面的简介并显示在卡片上，
  结果缓存在 `chrome.storage.local`，成功 30 天内、失败 1 天内不重复请求；抓取失败时卡片继续显示网址。
- **中英双语界面** —— 跟随系统 / 中文 / English；在设置页切换后，设置页与已打开的新标签页**同时实时生效**。
- **深浅色主题** —— 跟随系统 / 浅色 / 深色，首屏在渲染前同步应用（无闪白），顶栏按钮可一键循环切换。
- **卡片 / 列表双视图** —— 卡片信息更丰富；列表每行一条更紧凑、宽屏自动多列。顶栏切换，选择会被记住。
- **一键展开全部子文件夹** —— 把当前范围内的所有层级书签平铺到一起（子文件夹路径以标签标注），再点一次收起。
- **卡片尺寸三档** —— 紧凑 / 舒适 / 宽松（列表视图下不适用）。
- **显示开关** —— 网站图标、网址、搜索结果中的所在文件夹，均可单独开关。
- **实时同步** —— 书签增删改（`chrome.bookmarks` 事件）与设置变更（`chrome.storage.onChanged`）
  即时反映到界面，无需刷新页面。
- **手动刷新** —— 顶栏刷新按钮重新读取书签树，并保留当前 Tab、文件夹与搜索状态。
- **更多应用入口** —— 顶栏右侧的火焰按钮在新标签页打开 <https://i.eatmango.cn/>（作者的其他小工具）；
  窄屏下自动收成纯图标，不额外申请任何权限。
- **免安装开发预览** —— 内置 `chrome.*` 模拟层，在普通浏览器标签页里即可跑通主页与设置页。

## 安装（加载已解压的扩展程序）

1. 克隆或下载本仓库。
2. 打开 Chrome，进入 `chrome://extensions`。
3. 打开右上角的 **开发者模式 / Developer mode**。
4. 点击 **加载已解压的扩展程序 / Load unpacked**，选择**本仓库的根目录**（即包含 `manifest.json` 的目录）。
5. 新开一个标签页，书签主页即出现（首次安装会自动打开一次）。

要求 **Chrome 102+**（使用了 MV3 的 `favicon` 接口）。

> **改了代码之后**：必须在 `chrome://extensions` 里点击本扩展卡片上的 **⟳ 刷新**，
> 再重新打开新标签页，否则浏览器仍在运行旧版本代码。

## 使用方法

| 操作 | 效果 |
|------|------|
| 点击顶部 **Tab** | 切换到该文件夹的内容 |
| 点击 **文件夹卡片** | 下钻进入该文件夹；点面包屑的 **← 返回上级** 回退 |
| 点击 **书签卡片** | 在**当前窗口的新标签页**打开该书签 |
| `Ctrl`/`⌘` + 左键、鼠标中键 | 走浏览器原生行为（后台新标签页打开） |
| 顶栏 **展开全部 / 收起** | 平铺或收回当前范围内的所有子文件夹 |
| 顶栏刷新 / 视图 / 主题 / 齿轮 | 重新读取书签、切换卡片或列表视图、循环主题、打开设置页 |
| 顶栏 **更多应用**（火焰按钮） | 在新标签页打开 <https://i.eatmango.cn/> |

### 键盘快捷键（新标签页上）

| 按键 | 功能 |
|------|------|
| `/` | 聚焦搜索框 |
| `Enter` | 有匹配时打开第一条书签；无匹配时用所选搜索引擎搜索网页 |
| `Esc` | 清空搜索词，回到当前文件夹视图 |

## 设置项

在 `chrome://extensions` 中点击本扩展的「详情」→「扩展程序选项」，或在书签主页右上角点击齿轮图标。
所有设置通过 `chrome.storage.sync` 保存，登录同一账号的 Chrome 之间会同步。

| 设置 | 选项 | 默认 |
| --- | --- | --- |
| 语言 | 跟随系统 / 中文 / English | 跟随系统 |
| 主题 | 跟随系统 / 浅色 / 深色 | 跟随系统 |
| 视图模式 | 卡片 / 列表 | 卡片 |
| 卡片尺寸 | 紧凑 / 舒适 / 宽松 | 舒适 |
| 显示网站图标 | 开 / 关（失败时显示彩色首字母） | 开 |
| 显示网址 | 开 / 关 | 开 |
| 搜索结果显示所在文件夹 | 开 / 关 | 开 |
| 抓取网页简介 | 开 / 关（开启时申请「读取网站数据」权限） | 关 |
| 搜索引擎 | Google / Bing / 百度 | Google |

> 「抓取网页简介」默认关闭。开启时 Chrome 会弹出授权确认，扩展据此访问书签网址读取页面简介；
> 关闭时立即撤销该权限并清空已缓存的简介。

## 工作原理

- `scripts/background.js` —— service worker：首次安装时写入默认设置、点击图标时在新标签页打开主页、
  按需抓取书签页面简介并写入本地缓存（带成功/失败两种 TTL），权限被撤销时清空缓存。
- `scripts/newtab.js` —— 主页逻辑：把 `chrome.bookmarks.getTree()` 展平成索引，生成 Tab 与卡片，
  处理下钻、搜索、展开、主题/视图切换，并向后台请求缺失的简介。
- `scripts/shared.js` —— 共享模块 `B2H`：设置读写与订阅、中英文案字典与 `t()`、书签树索引与搜索、
  图标头像组件、网址与主题工具。
- `scripts/theme-init.js` —— 在样式表生效前同步应用主题，避免深色模式首屏闪白。
- 卡片上的普通左键点击由网格的委托监听器接管，走 `chrome.tabs.create`，因此链接总是开在**当前窗口的新标签页**。

## 权限说明

| 权限 | 用途 |
|------|------|
| `bookmarks` | 读取书签树并监听变化，这是主页的数据来源。 |
| `favicon` | 通过 Chrome 本地 `_favicon/` 接口取网站图标，不发起网络请求。 |
| `storage` | 保存并跨设备同步你的界面设置；网页简介缓存写入 `chrome.storage.local`。 |
| `optional_host_permissions: <all_urls>` | **可选权限**，仅在用户开启「抓取网页简介」时申请，用于访问书签自身的网址读取简介；关闭开关即撤销。 |

扩展不采集浏览记录、不上传任何数据、不含统计与广告代码。抓取简介时请求显式忽略凭据（不带 Cookie），
结果只留在本机。顶栏的「更多应用」只是一个普通外链（`<a target="_blank">`），只有你点击时才会打开，
不需要任何额外权限。

## 测试

本项目**没有自动化测试运行器**（零依赖），每次发布按 [`TEST_CASES.md`](TEST_CASES.md) 的清单在真实
Chrome 里手动过一遍。

免安装的本地快速运行（用模拟的 `chrome.*` 与 50 条示例书签）：

```bash
python3 -m http.server 8899
# 浏览器访问 http://localhost:8899/dev-preview.html
```

- `dev-preview.html?page=options` —— 直接预览设置页
- `dev-preview.html?clean=1` —— 隐藏顶部开发工具条，得到与真实页面一致的观感

预览页通过 `dev/mock-chrome.js` 模拟 `chrome.bookmarks` / `chrome.storage` / `chrome.tabs` /
`chrome.permissions`。模拟环境默认已授权「读取网站数据」，在设置页开关「抓取网页简介」即可看到简介
逐个填入卡片（简介为内置假数据，不联网）。模拟状态写入 localStorage（键名 `b2h-dev-storage`），
清掉该项即恢复默认。必须经 HTTP 访问（`file://` 无法 fetch 页面源码）。

## 发布打包

生成**只含扩展运行所需内容**的压缩包（运行文件 + 许可合规所需的 `LICENSE`）；
`dev/`、`dev-preview.html`、`docs/`、`scripts/` 与各类 Markdown 文档都会被排除。

```bash
./scripts/package.sh
# → dist/bookmarks2html-v<version>.zip（manifest.json 位于压缩包根目录）
```

版本号从 `manifest.json` 读取，并与 `CHANGELOG.md` 保持一致。该 zip 可直接上传 Chrome 应用商店，
或解压后用于「加载已解压的扩展程序」。

上架文案（单一用途声明、短描述、版本说明、逐权限理由、隐私政策地址、素材清单）见
[`docs/store-listing.md`](docs/store-listing.md)。

## 常见问题

**Q：不想要它接管新标签页了怎么办？**
删除 `manifest.json` 中的 `chrome_url_overrides` 字段，然后在 `chrome://extensions` 中重新加载扩展；
此时仍可通过工具栏图标打开书签主页。

**Q：为什么有些卡片显示的是彩色字母而不是图标？**
网站图标来自 Chrome 本地 favicon 缓存，从未访问过的站点取不到图标，此时显示由标题/域名生成的
彩色首字母，这是设计内的降级方案。

**Q：扩展会读取我的浏览记录吗？**
不会。只读取书签树与本地图标缓存，没有任何后台上传。唯一的网络行为是设置页里手动开启的
「抓取网页简介」：扩展访问书签网址本身以读取页面简介，请求不携带 Cookie，结果只缓存在本地；
不开这个开关就完全不会联网。
